# 大规模 ITC99 全扫描验证集

用户要求导入 b12、b15、b20、b21、b22 的 Nangate45 网表，删除旧 `_C` 组合验证电路，并已明确授权适配 PPO 时序接口。

## 设计选择

采用原生 FAN 的单帧全扫描模型。相比再次输出组合 `_C` 网表，这保留实际扫描触发器和工艺库来源；相比多周期时序 ATPG，不需要引入状态初始化搜索或改变 PPO 动作语义。

原解析器读取 Verilog 和 MDT，原 `buildCircuit(frame=1)` 将状态边界表示为 PPI/PPO。Python 桥接层保留 gate ID、引脚和故障位点，在内存中把 PPI/PPO 规范化成可控 PI/可观测 PO，供既有搜索、仿真、AIG、DeepGate2、PPO 和独立仿真使用。导出元数据保存真实扫描边界和向量顺序。输入向量顺序为真实 PI 后接扫描状态位；输出为真实 PO 后接下一状态位。

## 支持边界

只支持完整单链全扫描、单帧捕获。导出的捕获视图将异步 RN/SN 显式绑高，接口拒绝变量复位/置位。原始功能映射网表保存在 raw 目录。拒绝普通非扫描 DFF、部分扫描、锁存器、未知/高阻常量及未适配复合 MUX。扫描移位、时钟、SE、SI、QN 的测试协议故障不属于策略的功能 stuck-at 故障目录，不以自动检测冒充覆盖率；从分子和分母同时排除。保留 TIE0/1 的精确逻辑值。全扫描/常量电路使用未折叠功能数据故障，避免历史折叠逻辑对无观察点的常量缓冲漏计权重。

## 数据与配置

网表保存为 `FAN_ATPG/netlist/b{12,15,20,21,22}_nangate45.v`，b21 使用完整时序版本。固定来源、综合日志、SHA256、适配脚本存于 `datasets/itc99_nangate45`。旧验证集五张 `.bench` 与五张原语转换 `.v` 删除，旧验证特征和来源记录同步更新；其他训练数据与历史运行结果保留。`configs/fan_validation_full.json` 改为五张新网表及现有 Nangate MDT。协议与 checkpoint 版本升级，旧模型不混用。

## 验收

小型带反馈全扫描电路：穷举状态和 PI，核对下一状态/输出、AIG 每门等价、故障目录、ATPG 检测数、动态/静态压缩及独立故障仿真。非法扫描/锁存/活动复位语义须明确拒绝或声明约束。五张大电路完成原生解析、建图、故障目录导出与 AIG 等价抽查；准备验证特征，不启动全量 PPO 训练。执行现有相关回归测试，记录大电路中不能完成的检查，避免把加载成功描述为完整 ATPG 或训练完成。
