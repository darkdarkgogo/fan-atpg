# Verilog-native FAN design

User approved: support original FAN Verilog+technology-library input and delete the added native BENCH interface. Do not run training.

Architecture: original MdtLibBuilder/Techlib check -> original VlogNlBuilder/Netlist check -> original Circuit::buildCircuit(frame1) -> FAN fault extractor/session. No BENCH reader or Verilog-to-BENCH roundtrip in the training backend. Export the real internal primitive graph to Python; lower that graph directly to AIG for pinned pretrained DeepGate2 inference and257-dimensional features. Actor-critic PPO remains unchanged. Native protocol fan_verilog_v2 and checkpoint schema8 reject old BENCH protocol.

API contract: cpp_fan.catalog_stuck_at(netlist_path,library_path); cpp_fan.circuit_graph(netlist_path,library_path); StuckAtSession(netlist_path,library_path,backtrack_limit=100,seed=14,dtc_enabled=True,stc_enabled=True); run_stuck_at_ordered(netlist_path,library_path,ordered_fault_ids,...). Empty library or BENCH input rejected. Session dictionaries/count aliases keep structural compatibility. Native circuit export schema fan_circuit_graph_v1: gates list records gate_id,name,kind,fanins (native IDs), input_gate_ids, output_gate_ids, input_names,output_names. IDs contiguous native Circuit order. Catalog records include gate_id plus existing8 fields; node_name='g<gate_id>' and input_wire_name='g<source_gate_id>' (GO '-'), preserving pin occurrence; human names optional gate_name. Shared graph uses native IDs, not netlist string matching.

Input manifest version2/backend FAN/input_format verilog/cpp_fan_dir; each circuit requires name,netlist,library,graph,embeddings,metadata. Artifact graph is directly lowered AIG JSON, with original native circuit snapshot for validation (native_circuit) and anchors keyed g<gate_id>. Metadata schema fan_verilog_embeddings_v1 with native_catalog and immutable source/library/catalog/native-circuit/AIG/official encoder provenance. No BENCH key or old faultmap/aig_bench key accepted.

Default training/validation inputs: port existing 1024+5 source gate-level circuits to technology-mapped structural Verilog once, using explicit shipped FAN MDT primitive library. Training runtime only reads those Verilog files and library. Preserve old BENCH data as source provenance/history only; do not package as active training corpus. Provide small disjoint Verilog check manifests; prepare features/check interfaces but do not execute PPO training or model evaluation. Scope native supported gate-level semantics explicitly; reject unsupported sequential/primitive handling rather than silently simulate it incorrectly.

Checks: compile native parser extension; compare catalog and graph against original FAN Verilog CLI on representative circuits; verify mapping/Boolean AIG equivalence including multi-input and constant semantics; check strict source/library hashes and rejection of old configs; validate package contents and Linux shell syntax; no training.
